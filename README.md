# Codepath

เว็บฝึกเขียนโค้ดแบบวางแผนก่อนลงมือ: วาง Flowchart → อ่าน Error Trace → เขียนและรันโค้ด → ดูผลและความก้าวหน้า

## เริ่มใช้งาน

```powershell
npm install
npm run dev
```

เปิด http://localhost:3000

มี 3 ภารกิจ: ตรวจผลสอบ ตรวจอายุเข้าร่วมกิจกรรม และแจ้งเตือนอุณหภูมิ แต่ละบทมีแผน โค้ด ขั้นตอนที่ทำค้างไว้ XP และประวัติการรันแยกกัน เปลี่ยนได้จากเมนูด้านบนหรือหน้าเส้นทางเรียนรู้

## จำลองและตรวจแผน

- เชื่อมทางออกของเงื่อนไข “ใช่ / ไม่ใช่” ให้ครบ
- เลือกกล่องแล้วตั้งเครื่องหมายและค่าเกณฑ์ใน “การทำงานเมื่อจำลอง” ชื่อกล่องเป็นป้ายกำกับ ส่วนค่าที่ตั้งไว้เป็นตัวกำหนดพฤติกรรม
- Output กำหนดข้อความผลลัพธ์ Process รองรับบวกหรือคูณค่าคงที่
- ใส่ค่าทดลองแล้วกดเดินทีละขั้นหรือเล่นอัตโนมัติ มีหยุดชั่วคราวและเริ่มใหม่ กล่องปัจจุบันเป็นสีเหลือง กล่องที่ผ่านมาเป็นสีเขียว เส้นที่กำลังเดินมีสีเหลือง
- การแก้กราฟหรือค่าทดลองจะยกเลิกผลจำลองเดิม ไม่เพิ่ม XP จากการจำลอง
- ตรวจแผนจะแจ้งทางออกขาด กล่องที่ไปไม่ถึง จุดเริ่มต้นซ้ำ เส้นซ้ำ/เส้นที่ชี้ไปยังกล่องที่ไม่มีอยู่ และวงวน กดรายการเพื่อเลื่อนมุมมองไปยังกล่องผิดได้
- เมื่อโครงสร้างครบ ระบบตรวจผลจากแผนกับกรณีทดสอบ 5 กรณีของบทเรียน รวมค่าขอบเขตเกณฑ์ด้วย
- ตัวจำลองรอบนี้ตั้งใจใช้กราฟที่มีจุดจบเป็น Output จึงถือว่าวงวนทุกวงเป็นข้อผิดพลาด ยังไม่รองรับบทเรียน loop

ข้อมูลเดิมของบทเรียนผลสอบถูกอ่านและย้ายไปพื้นที่จัดเก็บแยกบทเรียนโดยคงต้นฉบับเดิมไว้ ปุ่มล้างข้อมูลจะล้างเฉพาะบทเรียนที่เปิดอยู่

ข้อมูลการฝึกเก็บใน localStorage ของเบราว์เซอร์ ไม่มีบัญชีผู้ใช้หรือฐานข้อมูลกลาง คำใบ้เป็นเนื้อหาประกอบบทเรียน ไม่ได้เชื่อมต่อบริการ AI สำรองประวัติเป็น JSON ได้จากหน้าความก้าวหน้า (ยังไม่รองรับนำเข้ากลับ)

## ตรวจสอบและเปิดใช้งาน

```powershell
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

ตัวทดสอบครอบคลุมตัวรันโค้ด การหยุด infinite loop กล้องซูม การตรวจกราฟ วงวน การคำนวณ และการจำลองทั้งสองแขนงของทุกบทเรียน มีการตรวจ UI จริงสำหรับเล่นทีละขั้น อัตโนมัติ และสลับบทเรียนแล้ว

Web Worker ช่วยไม่ให้หน้าจอค้าง แต่ไม่ใช่ระบบแยกโค้ดอันตรายอย่างสมบูรณ์ ก่อนให้บริการสาธารณะที่มีข้อมูลสำคัญ ควรแยกตัวรันไป origin หรือระบบประมวลผลเฉพาะ


## Dashboard สำหรับส่งงาน

เปิด `/dashboard` เพื่อเข้าหน้าภาพรวมโดยตรง หรือเลือกเมนู Dashboard ในเว็บ

- รวมประวัติจริงจากทั้งสามบทเรียน สูงสุด 50 ครั้งที่บันทึกไว้ต่อบทเรียน
- กรองบทเรียน วันที่เริ่มต้น/สิ้นสุด ผลผ่าน/ไม่ผ่าน และเลือกช่วง 7 หรือ 30 วัน
- การ์ดสรุป กราฟผลการฝึก กราฟกิจกรรมรายวัน พฤติกรรมการใช้เครื่องมือ ตารางรายบทเรียน และประวัติแบบแบ่งหน้า ใช้ตัวกรองเดียวกันทั้งหมด
- กดแถบกราฟเพื่อเจาะบทเรียน ดาวน์โหลดประวัติตามตัวกรองเป็น CSV ที่เปิดภาษาไทยใน Excel ได้
- เปิด “ทดลองด้วยข้อมูลตัวอย่าง” สำหรับนำเสนอหน้าชั้น ข้อมูลสาธิตไม่บันทึกทับข้อมูลจริง และมีป้ายระบุชัดเจน
- Dashboard นี้แสดงข้อมูลผู้ใช้ในเบราว์เซอร์ปัจจุบัน ไม่มีระบบรวบรวมข้อมูลทั้งห้องเรียน

### การนำขึ้นออนไลน์

โปรเจคใช้ Next.js พร้อมคำสั่ง build/start มาตรฐาน สามารถนำ source code ไปบริการโฮสต์ที่รองรับ Next.js ได้ ตั้ง Build command เป็น `npm run build` และ Start command เป็น `npm start` โดยไม่ต้องตั้งค่าฐานข้อมูลหรือ API key จากนั้นใช้ URL สาธารณะตามด้วย `/dashboard` สำหรับส่งอาจารย์ ผู้ชมเปิดโหมดข้อมูลตัวอย่างเพื่อทดลองได้ทันที

ไฟล์ source ZIP สำหรับส่งงานอยู่ใน `deliverables/Codepath-source.zip` (ไม่รวม node_modules, build และข้อมูลส่วนตัวในเบราว์เซอร์) ลิงก์ localhost ใช้ได้เฉพาะเครื่องที่รัน ไม่ใช่ URL สาธารณะสำหรับส่งงาน
